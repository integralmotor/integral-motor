# Integral Motor

App de **Rectificaciones Integral Motor** (de Daniel Alberto Calluela): presupuestos, órdenes de reparación, pagos y caja, cheques, clientes, proveedores, stock y precios.

- Se usa desde el navegador o instalada en el celular ("Agregar a pantalla de inicio").
- Se entra con una cuenta de Google habilitada. El administrador habilita a los demás en **Respaldo → Usuarios**.
- Los datos se guardan en Firebase (Google) y se sincronizan entre todos los dispositivos. Este repositorio tiene solo la app, no los datos.

`firestore.rules` es una copia de las reglas de seguridad que están cargadas en Firebase (Firestore → Reglas).
